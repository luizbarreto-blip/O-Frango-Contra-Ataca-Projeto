
# Registro de Uso de Inteligência Artificial

Este documento registra as principais interações com ferramentas de IA durante o desenvolvimento do O Frango Contra-Ataca.

## Registro 01

- Utilizamos IA para dar a ideia para o tema do nosso projeto e para decidir um nome do jogo.

  ## Registro 02
- Utilizamos IA para criar o esboço das classes do projeto, o que inclui quais classes teremos e o que as classes terão.
